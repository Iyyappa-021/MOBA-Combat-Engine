MOBA Combat Engine

Project Description

The MOBA Hero Combat Engine is a Java-based two-player combat simulation. Players can select heroes from three categories: Warrior, Mage, and Archer, and battle using basic and special attacks.

The project demonstrates Object-Oriented Programming concepts, multithreading, mana management, skill cooldowns, damage reduction, and custom exception handling.

Features

- Three hero categories: Warrior, Mage, and Archer.
- Multiple character choices.
- Basic attacks and special attacks.
- Mana consumption and regeneration.
- 15-second special skill cooldown.
- Armor and magic resistance-based damage reduction.
- Multithreaded combat execution.
- Custom exception handling for insufficient mana and skills on cooldown.
- Automatic battle result detection.

Technologies Used

- Programming Language: Java
- IDE: IntelliJ IDEA
- Version Control: Git and GitHub

How to Run

1. Download or clone this repository.
2. Open the Java source file in IntelliJ IDEA.
3. Compile and run the program.
4. Select a hero for Player 1 and Player 2.
5. Press Enter to start the battle.
